# krado

krado（クラード）は、Mac のウインドウをマス目に並べるためのアプリです。Windows の FancyZones の代わりを目指しています。

**kradoはエスペラント語でマス目の意味です。**

> krado is a window-tiling app for macOS, aiming to replace FancyZones.
> *krado* means "grid square" in Esperanto.

## Status / 状態

開発中（v0 プロトタイプ）。まだリリースはありません。

Work in progress (v0 prototype). No release yet.
