# krado

[English](README.md) | 日本語 · [変更履歴](CHANGELOG.ja.md)

**ウインドウをドラッグして、マス目に置くだけ。** krado は、macOS のウインドウを並べるメニューバーの小さなアプリです。設定は要りません。画面ごとに合ったマス目を自動で選びます。

![ウインドウをドラッグしてマス目に置く](docs/assets/demo/drag-snap.gif)

## 画面に合わせたマス目

**システム設定 → ディスプレイ**で選んでいる画面の大きさから、分け方を決めます。内蔵の画面も外付けの画面も、同じ決まりです。

| 画面 | マス目 | たとえば |
| --- | --- | --- |
| 大きい画面 | **4 × 2** | 高解像度の大型ディスプレイ（横がおよそ 2800 以上） |
| 中くらい | **2 × 2** | 1920 × 1080 や 2560 × 1440 などの一般的なモニター |
| 小さい画面 | **2 × 1** | 標準の大きさで使っている MacBook の画面 |
| とても小さい | **1 × 1** | 幅の狭い画面や低解像度の画面 |
| 縦置き | **1 × 2** | 縦向きにしたモニター（高さが足りない縦置きは 1 × 1） |
| ウルトラワイド | **4 × 1** または **4 × 2** | とても横長のモニター。高さが十分なら2段 |

![大きい画面・中くらい・小さい画面・とても小さい画面・縦置きのマス目](docs/assets/layouts.ja.png)

## 使い方

ウインドウのタイトルバーをドラッグします。ポインタのある画面にマス目が出るので、光っているマスで離すと、そこにぴったり収まります。マスの境目の近くでは、両側のマスにまたがります。

| | |
| --- | --- |
| **Shift + ドラッグ** — なぞったマスをまとめて覆います。 | ![Shift + ドラッグで複数のマスにまたがる](docs/assets/demo/shift-drag.gif) |
| **Option + ドラッグ** — マス目を無視して、好きな場所に置きます。 | ![Option + ドラッグでマス目を無視](docs/assets/demo/option-drag.gif) |
| **ドラッグ中に Esc** — そのドラッグでは、マスに収めません。 | ![Esc でマスに収めるのを取り消す](docs/assets/demo/esc-cancel.gif) |
| **キーボード** — **⌃⌘ + 矢印**で、操作中のウインドウを1マス動かします（端では隣の画面へ）。**⌃⌘⇧ + 矢印**で広げ、反対向きの矢印で縮めます。 | ![キーボードで動かす・広げる・縮める](docs/assets/demo/keyboard.gif) |

メニューバーのアイコンで、krado が動いているかが分かります。メニューには**ログイン時に起動**と**アップデートを確認…**があります。

## インストール

macOS 14 以降で使えます。

1. [Releases](https://github.com/KazinaG/krado/releases) から `krado-x.y.z.dmg` をダウンロードして開き、**krado** を**「アプリケーション」**へドラッグします。
2. krado を開きます。「検証できません」と出たときは：
   - **macOS 15 以降：**「完了」を押し、**システム設定 → プライバシーとセキュリティ**で**「このまま開く」**を押します。
   - **macOS 14：**「アプリケーション」の krado を Control キーを押しながらクリックし、**「開く」**を選びます。
3. krado に聞かれたら、**アクセシビリティ**を許可します。ほかのアプリのウインドウを動かしたり大きさを変えたりするのに必要です。許可すると krado が自動で気づきます。

アップデートのあとにアクセシビリティをもう一度求められたら、**システム設定 → プライバシーとセキュリティ → アクセシビリティ**で古い **krado** を削除し、新しい **krado** をオンにしてください。

## プライバシー

krado が見るのは、マウスのドラッグ、ドラッグ中の Esc キー、krado 自身のショートカットだけです。ウインドウはアクセシビリティを通して動かします。入力した文字や画面の中身は見ません。Mac の外と通信するのは、GitHub から更新情報を取りにいくときだけです。

## 困ったとき

- **ドラッグしてもマス目が出ない：** krado のメニューで状態を確かめ、**アクセシビリティ**で krado がオンになっているか確認してから、krado を開き直してください。
- **ウインドウがうまく収まらない：** アプリによっては、ウインドウの大きさや位置を変えられないものがあります。krado はそのままにします。
